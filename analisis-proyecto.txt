1. DESCRIPCIÓN GENERAL
================================================================================

Aplicación web full-stack para la gestión de una red estudiantil universitaria.
El sistema administra inscripciones, reinscripciones, calificaciones, horarios,
asistencia docente, tutorías, trabajos de investigación y generación de
certificados/records académicos para una institución educativa venezolana.

Roles del sistema:
  - Administrador
  - Docente (con 4 subroles internos: Presencial Fijo, Temporal, Asesor de
    Proyecto/Metodología, Tutor)
  - Estudiante
  - Administrativo
  - Control_de_Estudios
  - Tutor_Externo


2. TECH STACK
================================================================================

Backend:

7. MÓDULOS PRINCIPALES Y RESPONSABILIDADES
================================================================================

Backend:

  - authController:     Login con verificación bcrypt, generación y refresh de
                        tokens JWT (expiración 5 min)
  - genericController:  CRUD dinámico para 22 tablas con auditoría automática,
                        JOINs especializados para tablas con relaciones
  - checkJWT:           Middleware que valida JWT en cada request protegido
  - asistenciaService:  Gestión de asistencia docente: marcar, verificar,
                        reportes de horas impartidas
  - CalificacionService:Sincronización de notas entre estudiantes_asignatura
                        y calificaciones, cálculo de estado (>=10 = Aprobado)
  - DashboardService:   KPIs: estudiantes activos, docentes activos,
                        calificaciones pendientes, ofertas activas,
                        estudiantes por carrera
  - HorarioService:     Consultas de horarios por oferta académica o por
                        docente
  - InscripcionService: Inscripción completa: valida datos, registra periodo,
                        asigna materias
  - ReinscripcionService:Reinscripción con avance de nivel, sugiere siguiente
                        nivel académico
  - InvestigacionService:Manejo de tutorías internas/externas, creación de
                        trabajos de investigación
  - bitacora:           Auditoría: registra hora, fecha, IP, usuario, acción,
                        módulo, ID de registro y detalles de cada operación
  - generateJWT:        Genera tokens JWT con payload {id, rol}

Frontend:

  - login.js:           Autenticación, almacena token/rol/rutas en localStorage,
                        registra bitácora de inicio de sesión
  - tokenManager.js:    Monitorea expiración del JWT, alerta 2 min antes,
                        redirige al login al expirar
  - shared.js:          Inyección de header compartido, validación de rutas,
                        bloqueo de herramientas de desarrollador para no-admins,
                        inicialización de Tom Select
  - genericTable.js:    Componente reutilizable para CRUD: carga datos,
                        renderiza tabla, acciones (editar/eliminar/ver carnet)
  - paginacion.js:      Componente de paginación de tablas
  - inicio.js:          Dashboard con indicadores gráficos


8. SEGURIDAD
================================================================================

  - JWT con expiración de 5 minutos para todas las API (excepto login)
  - Contraseñas hasheadas con bcrypt (10 rounds)
  - Contraseñas auto-generadas de 8 caracteres alfanuméricos para nuevos
    usuarios
  - Control de acceso basado en roles (whitelist de rutas por rol)
  - Bloqueo de herramientas de desarrollador (F12, Ctrl+Shift+I/J/C/U,
    clic derecho) para usuarios no administradores
  - Registro de IP del cliente en todas las operaciones (header x-client-ip
    + API externa ipify)
  - Auditoría completa (bitácora) de toda operación Crear/Actualizar/Eliminar


9. ARQUITECTURA Y PATRONES
================================================================================

  - Generic Controller Pattern: Un solo controlador maneja CRUD para todas
    las tablas del sistema, reduciendo código repetitivo
  - Desnormalización controlada: Varias tablas almacenan nombres completos
    junto a las FK para evitar JOINs frecuentes
  - Sincronización bidireccional de notas: estudiantes_asignatura se
    sincroniza automáticamente con calificaciones
  - Validación dual: Frontend valida rutas desde localStorage + Backend
    valida JWT en cada request
  - Códigos de carnet únicos: EST-XXX para estudiantes, PROF-XXX para
    docentes (3 dígitos aleatorios)
